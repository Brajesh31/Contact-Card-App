# ⚙️ Operations guide

## Routine checks
- Install dependencies from the npm lockfile.
- Run the docs validator.
- Run the production build.
- Review dependency alerts.
- Confirm no real contact data or credentials enter commits.

## Build and deploy
See [deployment.md](deployment.md). The build output is `build/`; no production provider is configured in the source.

## Incident handling
For a security concern, follow [SECURITY.md](../SECURITY.md). For application defects, open a sanitized bug report using the issue form.
