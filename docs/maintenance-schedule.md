# 🗓️ Maintenance schedule

Suggested cadence, adjust to project activity:

| Frequency | Activity |
|---|---|
| Every change | Build and validate affected docs |
| Weekly | Review Dependabot and GitHub security alerts |
| Monthly | Review dependencies, known issues, and roadmap |
| Each UI change | Update page/component docs and capture real screenshots |
| Each release | Update changelog, version notes, deployment evidence |
| Each data feature | Review privacy, data lifecycle, deletion, and backup implications |
