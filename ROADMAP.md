# 🧭 Roadmap

This roadmap describes proposals, not implemented features. Priorities may change after maintainer review.

## ✅ Existing baseline
- [x] Add contacts through a controlled form.
- [x] Share contacts through React Context.
- [x] Render saved contacts as cards.
- [x] Provide narrow-screen CSS rules.

## 🔜 Recommended next steps
- [ ] Add stable IDs instead of array indexes as list keys.
- [ ] Add unit tests for context, form validation, and contact rendering.
- [ ] Add edit and delete actions.
- [ ] Add explicit success and validation feedback.
- [ ] Add persistence only after choosing and documenting a privacy model.
- [ ] Make phone and email actions functional with appropriate links.
- [ ] Audit keyboard operation, labels, contrast, and screen-reader output.
- [ ] Add verified screenshots of the running app.

## 💡 Longer-term decisions
- [ ] Decide whether backend synchronization is required.
- [ ] Decide whether authentication and multi-user contact ownership are in scope.
- [ ] Evaluate import/export and duplicate detection.
- [ ] Reassess the build toolchain before migrating away from Create React App.

## Definition of done
A roadmap item is complete only when the implementation, tests, documentation, and relevant evidence have been merged and verified.
