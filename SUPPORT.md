# 🆘 Support

## Before asking
1. Read the [README](README.md) and [documentation index](docs/README.md).
2. Confirm the issue on the latest `main` branch.
3. Record your Node.js and npm versions.
4. Include the exact command, expected behavior, actual behavior, and sanitized error output.

## Where to ask
- Use GitHub Issues for reproducible bugs and actionable feature requests.
- Use the repository owner's GitHub profile for private security or conduct reports.

## Useful diagnostics

```bash
node --version
npm --version
npm install
npm run build
```

Never attach real contact lists, private email addresses, phone numbers, credentials, or environment files to a support request.
