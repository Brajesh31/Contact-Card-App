# 🤝 Code of Conduct

## Our commitment
We aim to keep collaboration around Contact Card App respectful, constructive, and welcoming to people with different backgrounds and experience levels.

## Expected behavior
- Be respectful and assume good intent.
- Give actionable, evidence-based feedback.
- Welcome questions from beginners.
- Respect privacy. Never publish another person's contact details or credentials.
- Focus discussion on the code and the problem.

## Unacceptable behavior
- Harassment, discrimination, threats, or personal attacks.
- Doxxing or sharing private information.
- Trolling, deliberate disruption, or abusive language.
- Submitting malicious code, secrets, or harmful payloads.

## Enforcement
Project maintainers may edit or remove contributions that violate these standards and may close discussions or restrict participation for repeated or severe violations.

## Reporting
Report conduct concerns privately through the repository owner's GitHub profile contact route. Do not include sensitive personal data in a public issue.

## Scope
This code applies in repository issues, pull requests, reviews, discussions, and project-related spaces.
